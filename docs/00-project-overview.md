
# Project Overview

## Purpose

This project demonstrates my transition from content strategy to professional technical writing by documenting and modernizing the documentation experience for the Plane project management platform.

Over the past __5__ years, I have created user-focused content, developed content strategies, and optimized digital experiences for healthcare technology products. 

Through this project, I aim to showcase how those skills translate into technical documentation by applying industry-standard documentation practices, Docs-as-Code workflows, Git-based version control, and structured authoring.

The objective is not to rewrite Plane's existing documentation but to analyze, improve, and redesign selected documentation components while following the workflow used by modern SaaS documentation teams.

---

## Background

Throughout my career, I have worked extensively on healthcare and AI-focused content, where understanding complex products and communicating them clearly has been a key responsibility. While this experience strengthened my ability to simplify technical concepts, I wanted to expand my expertise into structured technical documentation.

This repository represents the practical application of those skills through a realistic documentation modernization project.

---

## Project Objectives

The primary objectives of this project are to:

- Demonstrate an end-to-end technical documentation workflow.
- Analyze an existing SaaS documentation portal from a Technical Writer's perspective.
- Identify documentation gaps and usability improvements.
- Design a scalable information architecture.
- Create professional product documentation using structured authoring principles.
- Develop API documentation following industry best practices.
- Demonstrate Git-based collaboration using branches, commits, Issues, Pull Requests, and Releases.
- Showcase AI-assisted documentation while maintaining editorial review and technical accuracy.

## Documentation Workflow

This project follows a documentation lifecycle similar to that used by modern SaaS organizations.

1. Research
2. Documentation planning
3. Content analysis
4. GitHub Issue creation
5. Feature branch development
6. Documentation authoring

8. Pull Request

10. Release
11. Documentation publishing
